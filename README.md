# FusionHD 多媒体融合显示

**基于安路 EG4S20 FPGA 的校园安全音视频终端**

从 TF 卡读取图片与中文语音，经 HDMI 直接驱动独立显示器，支持本地交互与应急提示。本仓库用于公开展示，完整 RTL、TD 工程和含源码节选的技术报告由团队私有保存。

![FusionHD 实物系统](images/system-overview.jpg)

## 功能

- 四页 BMP 图片手动切换与自动轮播，支持末页回到首页。
- 支持 640×480 原尺寸，以及 320×240 图像二倍最近邻映射。
- 中文语音解码与 HDMI 音频输出，支持静音及恢复。
- 四档亮度、滚动文字、PCM 波形和运行状态显示。
- 支持 2 / 5 / 10 s 最短轮播间隔，以及应急箭头和提示音。
- 正常 TF 卡条件下可断电恢复，独立连接显示器播放，无需电脑参与运行时媒体处理。

正式演示素材为四张 640×480 图片。上述缩放能力不表示支持任意分辨率；系统不属于通用视频文件播放器。

## 硬件与连接

| 项目 | 配置 |
|---|---|
| FPGA | 安路 EG4S20BG256 |
| 开发板 | HX4S20C V1.0 |
| 开发工具 | Tang Dynasty 6.2.1 |
| 媒体存储 | TF 卡、共享 SDRAM |
| 输出 | HDMI B → 显示器 HDMI 输入 |

使用 Mini HDMI 输入的便携显示器时，显示器端需要匹配的 Mini HDMI 转接头，并按显示器要求单独供电。电脑用于开发与下载；早期预览通过 HDMI 采集卡接入电脑 USB，笔记本 HDMI 接口不作为视频输入。

## 按键操作

操作对象为白色 KEY 按键，非黑色 SW 开关。

| 按键 | 短按 | 长按约 2 s |
|---|---|---|
| KEY1 | 复位 | 仍为复位 |
| KEY2 | 下一页 | 静音 / 恢复语音 |
| KEY3 | 切换亮度 | 进入 / 退出应急模式 |
| KEY4 | 自动 / 手动 | 切换轮播间隔 |

## 验证摘要

| 项目 | 已记录结果与范围 |
|---|---|
| 功能仿真 | 18 项模块 RTL 仿真通过 |
| 图像对照 | 同一采集链路、四页固定 ROI，合计 588800 像素比较无差异；不等同于全帧或任意链路无损 |
| 存储优化 | BRAM9K 从 52 块降至 6 块，下降 88.46% |
| 当前资源 | 7980 LUT、3602 REG、6 BRAM9K、4 DSP、2 PLL |
| 连续运行 | 1799.97 s，89 次页面循环回绕，四句语音各完成 89～90 次播报 |
| 可靠性 | 配置回读、正常卡断电恢复、无卡诊断及应急输出已验证 |
